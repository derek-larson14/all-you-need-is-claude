Using the Supermetrics Analyzer skill, find what we're missing across all three platforms (Meta, Google, TikTok) using the CSVs in `data/`.

Apply the patterns in `references/hidden-wins-rules.md`. Group findings into four sections:

1. **Scale these**: underspent high-efficiency ad sets, low-frequency outperformers, geo/device/placement pockets

3. **Data quality**: anything that looks like a tracking artifact rather than real performance change
4. **Cut these**: genuine losers with sustained sub-0.8x ROAS

Show the math for each finding: which rule triggered, what numbers, what date range. Each item ends with a specific recommended action.

Sort within each section by potential dollar impact.
