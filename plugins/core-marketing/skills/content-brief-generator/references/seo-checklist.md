# SEO checklist for briefs and outlines

Apply these as defaults. The marketer can override; don't ask permission for the basics.

## Keyword placement
- Primary keyword in: H1, first 100 words of body, at least one H2, meta description, URL slug, conclusion
- Secondary keywords: at least once each in body, ideally in an H2 or H3
- Don't keyword-stuff. If the primary keyword appears more than ~1% of total words, you're overdoing it
- Use natural variations and synonyms — Google's been smart about this for a decade

## Meta description
- 150-160 characters max (155 is the safe target)
- Include primary keyword once, naturally
- End with an implicit or explicit CTA
- Don't promise something the article doesn't deliver

## Title tag (separate from H1 if needed)
- 50-60 characters
- Primary keyword toward the front
- Brand name at the end if it fits, otherwise drop it

## URL slug
- 3-5 words
- Primary keyword
- Hyphens, not underscores
- No stop words (a, the, of) unless removing them changes meaning

## Header hierarchy
- One H1 only — the title
- H2s for major sections (4-6 typical for 1500 words)
- H3s only when an H2 has genuinely distinct sub-points
- Skip H4+ unless the piece is a long reference doc

## Internal linking
- 2-4 internal links per 1000 words
- Anchor text should describe the destination, not "click here"
- Link to commercial pages from informational pieces (TOFU → MOFU/BOFU pathway)

## External linking
- 1-3 external links to authoritative sources per 1000 words
- Open in new tab
- Cite sources for stats, claims, and quotes — always

## Image SEO
- Descriptive filenames before upload (sustainable-activewear-hero.jpg, not IMG_4523.jpg)
- Alt text describes the image and includes keyword *only if natural*
- Compress before upload (under 200KB for hero, under 100KB for inline)

## Search intent matching
- **Informational** ("how to", "what is"): long-form, structured, comprehensive. CTA is soft (subscribe, related reads)
- **Commercial** ("best X", "X vs Y"): comparison, criteria, pros/cons. CTA is medium (free trial, demo)
- **Transactional** ("buy", "pricing", "near me"): short, scannable, trust signals, social proof. CTA is direct (buy, book)
- **Navigational** ("brand name + X"): minimal SEO concern; serve the existing audience cleanly

If the brief's intent and content type don't match (e.g. transactional intent + 2000-word essay), flag it.
