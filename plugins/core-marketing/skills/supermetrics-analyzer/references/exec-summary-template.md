# Weekly Executive Summary — Default Template

Default voice: direct, numerate, no hedging. Match the user's voice if they've uploaded a brand voice doc or sample report; this template is the fallback.

## Structure

```
# Weekly Performance Summary
**Week of {Mon date} – {Sun date}**

## TL;DR
- {3-5 bullets, each one sentence, lead with direction (up/down/flat) and the dollar or percent magnitude}

## Headline KPIs
| Metric | This week | Last week | Δ |
|---|---|---|---|
| Spend | ${...} | ${...} | {+x.x%} |
| Revenue | ${...} | ${...} | {+x.x%} |
| ROAS | {x.xx}x | {x.xx}x | {+x.xx} |
| CAC | ${...} | ${...} | {+x.x%} |
| Conversions | {n} | {n} | {+x.x%} |

## What's working
- {Channel / campaign / creative}: {one-line why with numbers}
- ...

## What's broken
- {Channel / campaign / creative}: {one-line why with numbers}
- ...

## Channel breakdown
| Channel | Spend | Revenue | ROAS | WoW ROAS |
|---|---|---|---|---|
| Meta | ${...} | ${...} | {x.xx}x | {+x.xx} |
| Google Ads | ${...} | ${...} | {x.xx}x | {+x.xx} |
| TikTok | ${...} | ${...} | {x.xx}x | {+x.xx} |

## What I'd do Monday
1. {Specific action with named campaign or creative}
2. ...
3. ...

## Data quality note
{Row counts, date range used, any gaps or anomalies the marketer should know about.}
```

## Tone rules

- **Lead with direction.** "Spend up 12% to $48,200" beats "Spend was $48,200, which is up from last week's $43,000."
- **Numerate every claim.** No "performed well" — always "ROAS 3.4x, 22% above account average."
- **Single-sentence bullets.** If you need two sentences, it belongs in a deeper section, not the TL;DR.
- **Recommend, don't observe.** "Pause Cold-Broad-Test-2" beats "Cold-Broad-Test-2 has been underperforming."
- **No hedging.** Cut "appears to," "seems to," "may indicate." If you're not sure, say "low confidence: ..." and move on.

## Length target

- TL;DR: 3-5 bullets, ~50 words
- Full summary: 400-600 words for the exec layer
- If the user asks for "long form," append a per-campaign appendix below the recommended actions
