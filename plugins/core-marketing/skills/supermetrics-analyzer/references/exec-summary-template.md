# Weekly Executive Summary — Default Template

Default voice: direct, numerate, no hedging. Match the user's voice if they've uploaded a brand voice doc or sample report; this template is the fallback.

## Structure

```

- {Direction + magnitude — one sentence, e.g. "Meta carrying the account; Google flat; TikTok degrading."}
```

## Tone rules

- **TL;DR is always 3 bullets, one sentence each.** Lead each one with the direction (up/down/flat) and the magnitude. Cover spend or revenue, ROAS or efficiency, and the channel narrative.
- **Use tables for comparative data.** KPI deltas, channel breakdowns, what's working, what's broken — all tables. Prose blurbs are reserved for the TL;DR and the "What I'd do Monday" actions.
- **Numerate every claim.** No "performed well" — always "ROAS 3.4x, 22% above account average."
- **Recommend, don't observe.** "Pause Cold-Broad-Test-2" beats "Cold-Broad-Test-2 has been underperforming."
- **No hedging.** Cut "appears to," "seems to," "may indicate." If you're not sure, say "low confidence: ..." and move on.

## Length target

- TL;DR: 3 bullets, ~50 words total
- Tables: as many rows as needed, but don't bloat — top 3-5 winners and losers, not every single line item
- "What I'd do Monday": 3-5 numbered actions
- If the user asks for "long form," append a per-campaign appendix below the recommended actions
