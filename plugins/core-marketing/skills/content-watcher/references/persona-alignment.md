# Persona alignment rubric

A piece can be word-perfect and compliance-clean and still be wrong because it's speaking to the wrong person. This rubric tells you how to spot that.

## The four dimensions

For each dimension, ask: does the copy match the persona the brand book describes?

### 1. Vocabulary level
- Does the copy use jargon the persona would know — and avoid jargon they wouldn't?
- Example mismatch: persona is a casual gym-goer; copy uses "concentric vs. eccentric loading."
- Example mismatch: persona is a coach; copy explains "what is a deadlift."

### 2. Pain points and aspirations
- Does the copy address what the persona actually cares about?
- The brand book persona usually lists concrete pains (e.g. "no time to prep gear before a run") and aspirations (e.g. "wants to PR a half marathon this fall"). The copy should echo at least one.
- Example mismatch: persona's stated pain is "won't pay $300 for shoes that wear out in 6 months"; copy leads with "premium luxury craftsmanship."

### 3. Cultural context
- References, idioms, music, sports, places — would the persona catch them?
- Example mismatch: persona is "29-year-old urban parent"; copy references the 1986 Mets.
- Example mismatch: persona is global; copy uses American-only references without context.

### 4. Channel and tone fit
- Some personas live on LinkedIn; some live on TikTok. The copy should match where it'll appear AND the persona's relationship with that channel.
- Example mismatch: TikTok caption written like a press release.
- Example mismatch: B2B email written in influencer-speak.

## Verdict calibration

- Pushes toward **Hold** — the copy is for a fundamentally different audience than the brand serves. (Copy for "elite ultramarathoners" when the brand is "weekend trail walkers.")
- Pushes toward **Revise** — the copy is in the right neighborhood but drifts on one or two dimensions.
- Stays a note under **Approve** — minor drift, easy to recognize once pointed out.

## A useful test

Read the copy out loud as if you were the persona. Does it land? If you have to translate the copy to make it work for them, the verdict is **Revise**.

If the brand book lists multiple personas, identify which persona the brief was written for (the brief should say). If the brief didn't specify and the copy is generic, that's worth flagging as a note under **Approve**: "Couldn't tell which persona this is for. The brief should have specified."
